
# Oeste Librería



## 📝 Descripción Breve
Oeste Librería es un E-Comerce orientado a la compra de libros. El sitio web permite a los usuarios navegar a través de un catálogo seleccionado de libros, gestionar dinámicamente un carrito de compras, simular el procesamiento de la orden mediante una pantalla de carga y completar un formulario detallado con los datos de envío. para finalizar este E-Comerce se encuentra en Hurlingham sobre la Avenida Vergara.

## Instrucciones para instalar y correr el proyecto.

### 1. Clonar el repositorio

### 2. Pararse sobre la carpeta del proyecto
una vez parados sobre la carpeta del proyecto hay que utilizar npm install

### 3. correr el proyecto en modo desarrollo
una vez finalizada la instalacion de dependencias escribir por terminal npm run dev para levantar el repo de manera local

### 4. entrar al localhost
en la terminal indicara el link para poder ver visualmente la pagina en modo desarrollo. a continuacion dejo la URL: http://localhost:5173
